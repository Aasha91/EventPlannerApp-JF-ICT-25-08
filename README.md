## Project Description

The Event Planner App is an Android application that helps users create, organize, search, and manage their events. It also supports reminders for upcoming events.

## Features

* Create events with a name, date, time, and description.
* View upcoming events sorted by date and time.
* View past events separately.
* Edit existing events.
* Delete events with a confirmation message.
* Search events by name or date.
* Schedule reminders and receive notifications.
* Validate user inputs.
* Display helpful empty-state messages.

## Technologies Used

* Android Studio
* Java
* XML
* SharedPreferences
* Android Notifications and AlarmManager

## How to Run

1. Download or clone this repository.
2. Open Android Studio.
3. Select **Open** and choose the downloaded project folder.
4. Allow Gradle to sync.
5. Start an Android emulator or connect an Android device.
6. Run the application using the **Run** button.
